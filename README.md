# Bangumi 偏好评分

在 Bangumi 内的浮动窗口比较条目，得到保存在本地的两位小数偏好评分。书籍、动画、音乐、游戏、三次元分别评分，各类别需要至少 50 个有 1–10 分评分的条目。只为已完成的公开收藏评分（含未评分条目）；本人主页可每轮 20 次连续细化（优先比较分数接近的条目），并在检查、选择和确认后批量更新 Bangumi 评分。

```sh
npm ci
npm run build
```

组件：[个性化评分](https://bgm.tv/dev/app/7267)。开发版本已在登录状态下验证；正式使用需等待 Bangumi 审核。自行构建后，将 `dist/bangumi-preference-rating.js` 放入组件版本的脚本栏。本人主页评分统计下有「逐项细化评分」入口（支持全选 / 取消全选）；条目详情页有「偏好评分」入口；「个性化」面板可选择算法。

主页「查看偏好排名」按类别显示细化分数，可拖动条目预览并保存手动顺序，模型继续计算评分，可切换查看模型排序且保留手动顺序；评分展开程度可调整中段分差；建议最低 4 分，9 分目标约 1/40，10 分只由用户在 Bangumi 手动决定，并列条目同分。支持继续比较、撤销、跳过、模型切换和 JSON 备份。数据按用户保存在当前浏览器、当前域名下；换域名或设备请导出 / 导入。分数是近似建议，区间不是校准后的置信区间。

开发检查：`npm run check && npm test && npm run build`（Node 24+）。实现取舍和兼容性见 [开发说明](docs/implementation.md)。
